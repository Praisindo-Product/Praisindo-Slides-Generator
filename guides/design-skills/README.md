# Design skills

General design guidance from public skill collections, kept here as background reading for visual
judgement: composition, restraint, hierarchy, polish. They were written for web interfaces and
image generation, so read them for taste, not for rules.

Where they disagree with `guides/slide-guidelines.md` or `guides/design-system.md`, the Praisindo
guides win: Libre Franklin, the light tokens, the engine's components, plain copy, no decoration.

| Skill | Source | Read it for |
| --- | --- | --- |
| `design-taste-frontend/` | Leonxlnx/taste-skill | Avoiding generic, template-looking output |
| `high-end-visual-design/` | Leonxlnx/taste-skill | Spacing, contrast and finish |
| `minimalist-ui/` | Leonxlnx/taste-skill | Restraint and hierarchy |
| `stitch-design-taste/` | Leonxlnx/taste-skill | A design-system-first way of working |
| `brandkit/` | Leonxlnx/taste-skill | How identity systems are presented |

Versions are recorded in `skills-lock.json`, as in WMS-IMS Ultimate, where these were first adopted.
